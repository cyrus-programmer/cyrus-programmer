## About

I am a **Flutter developer and independent iOS app creator** based in Karachi, Pakistan. I build **cross platform mobile applications** for iOS and Android, and I ship them all the way to the App Store myself: architecture, offline sync, subscriptions, ASO, review, release.

- **10+ published iOS apps** across AI, health, fintech, productivity, and casual gaming
- Former **Flutter Lead** at Trisol Technologies, 2022 to 2026
- **Top Rated on Upwork** with 100% Job Success Score
- BSc Software Engineering, **FAST NUCES** Pakistan
- Background in **applied ML research**: medical imaging, transformer segmentation models, custom NLP tokenizers

I work end to end. That means clean Riverpod state, a real local database with Drift or SQLite, working offline first sync, RevenueCat paywalls that actually convert, and a build that passes App Store review the first time.
